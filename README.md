# shot-ocr

Инструмент для Windows на Rust: скриншот области экрана → распознавание текста → буфер обмена.

## Возможности (план)

- захват выделенной области экрана;
- распознавание через встроенный Windows.Media.Ocr (без внешних сервисов);
- результат сразу в буфер обмена;
- глобальный hotkey;
- опционально: сохранение скриншота с текстом.

## Стек

- Язык: Rust (Windows)
- Планируемые библиотеки: `windows-rs` (Win32 + Media.Ocr), `arboard` (буфер), `global-hotkey`

## Сборка и запуск

```bash
cargo build --release
cargo run --release
```
